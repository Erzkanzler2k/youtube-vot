## v1.7.0 — офлайн-экран

- При пропадании сети вместо ошибки YouTube — **аккуратный тёмный экран
  «Нет соединения»**: логотип, подсказка и кнопка **«Повторить»**.
- Как только интернет **возвращается, приложение перезагружает страницу само** —
  без лишних нажатий.
- Ошибки фоновых ресурсов (картинки, треки) экран не показывают — только
  реальный обрыв загрузки главной страницы.

По-прежнему: без рекламы, без входа, закадровый перевод русским голосом и субтитры.
Собрано и опубликовано GitHub Actions автоматически.
