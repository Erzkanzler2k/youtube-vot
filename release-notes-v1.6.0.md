## v1.6.0 — страна рекомендуемого контента

- На стартовом экране — строка **«Контент: …» с выбором страны** (тап по ней).
- По умолчанию подставляется **страна устройства** (локаль), можно поменять на
  любую из списка: Россия, Украина, Беларусь, Казахстан, США, Германия, Франция,
  Турция, Индия, Южная Корея и другие — лента рекомендаций и «Популярное»
  перестроятся под выбранный регион.
- Выбор **запоминается** — при следующих запусках применяется автоматически
  (вернуть «как на устройстве» можно в любой момент).
- Регион действует и на вкладки нижней навигации.

По-прежнему: без рекламы, без входа, закадровый перевод русским голосом и субтитры.
Собрано и опубликовано GitHub Actions автоматически.
