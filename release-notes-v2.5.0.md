# Что нового в 2.5.0

### 🛡 Нативный обход блокировок
- Вместо самописного userspace TCP-стэка используется native `hev-socks5-tunnel` и локальный SOCKS5-прокси ByeDPI.
- В TUN попадает только WebView-провайдер; собственный процесс приложения остаётся вне TUN и не зацикливает прокси.
- Native-библиотеки собираются для `arm64-v8a`, `armeabi-v7a`, `x86` и `x86_64`.

### 🐛 Исправлено
- Яндекс Паспорт больше не открывается автоматически в браузере при истечении токена авторизации.
- В CI и локальной сборке подключён Android NDK; native-библиотеки добавляются в APK как `lib/<abi>/*.so`.
