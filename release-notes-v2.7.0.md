# Что нового в 2.7.0

Три новые функции нижней панели и игрока плюс серия исправлений стабильности.

### ✨ Добавлено
- **🔍 Поиск на YouTube** — новая кнопка в нижней панели: вводите запрос, страница
  результатов открывается с учётом выбранной страны контента. Вставленная в поле
  ссылка YouTube открывается как видео.
- **📤 Поделиться чистой ссылкой** — кнопка отправляет адрес текущей страницы без
  трекинг-параметров (`si`, `feature`, `pp`, `app`, `utm_*`, `source_ve_path`,
  `redir_token`).
- **🖼 Картинка-в-картинке** — свернули приложение во время полноэкранного видео?
  Плеер продолжит играть в уголке экрана. Разворачивание возвращает на страницу.
  Работает и на Android 7–7.1 (базовый PiP), и на Android 8+.

### 🐛 Исправлено
- **Дубли `hl`/`gl` в адресах.** При обновлении страницы или повторном выборе
  страны параметры региона могли добавляться второй раз — теперь они заменяются.
- **Падение рендер-процесса WebView.** На слабых устройствах процесс отрисовки
  иногда умирает и экран оставался чёрным навсегда — страница теперь автоматически
  перезагружается (`onRenderProcessGone`).
- **VoT больше не инжектится на чужие страницы** — только на хосты YouTube.
  Раньше условие пропускало любые `http*`-адреса (например, top-frame переходы на
  `googlevideo.com` получали скрипты перевода зря).

### 📋 Проверено
- Сборка Java 8 проходит (aapt2 → javac → d8 → ZipFix → zipalign).
- Новые ресурсы (`ic_search`, `ic_share`, строки) собраны aapt2 без ошибок.
