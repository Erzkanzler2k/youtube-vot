# Что нового в 2.1.0

### ⚙️ Кнопка настроек
- В нижней панели появилась шестерёнка — все настройки теперь под рукой, не только при первом запуске.

### 🌍 Страна контента
- Выбор страны рекомендаций можно менять в любой момент из настроек.

### 🔄 Автообновление
- Появился переключатель: можно отключить проверку новых версий, если не хочется обновляться.

### 🛰️ Сервер перевода
- Можно указать свой адрес воркера озвучки для тех, у кого не работает встроенный.

### 🚪 Сброс настроек
- Одна кнопка возвращает страну, автообновление и сервер перевода к значениям по умолчанию.
