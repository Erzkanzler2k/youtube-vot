# Что нового в 2.4.1

### 🎙 Умный автозапуск озвучки
- Если язык видео уже совпадает с целевым языком (например, `ru → ru`), автоматическая озвучка больше не запускается.
- Ручной запуск перевода через кнопку VoT по-прежнему доступен.
- Если язык не удалось определить, приложение сохраняет прежнее поведение и не блокирует автоперевод.
