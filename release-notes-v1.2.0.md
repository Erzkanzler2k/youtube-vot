## v1.2.0 — визуальная прокачка

**Внешний вид (уровень A):**
- Material-иконки вместо текстовых кнопок: назад, вперёд, обновить, выход (VectorDrawable 24dp, тач-таргеты 48dp, contentDescription для доступности).
- Навигация по истории WebView: «назад/вперёд» активны, только когда есть куда ходить (неактивные — полупрозрачные).
- Тонкий акцентный прогресс-бар загрузки над страницей, исчезает при 100%.
- Вид медиа-приложения: статус-бар скрыт, нижняя системная панель в цвет фона YouTube.
- Убраны белые вспышки между страницами: фон WebView и оверскролл в #0F0F0F, цветное свечение краёв отключено.
- На странице мобильного YouTube скрываются банеры «Откройте в приложении YouTube» и cookie/consent-попапы (CSS + MutationObserver-чистильщик удаляет узлы целиком).

Всё по-прежнему: без рекламы (сетевая блокировка + косметика), без входа в аккаунт, закадровый перевод русским голосом и субтитры через встроенный VoT.
