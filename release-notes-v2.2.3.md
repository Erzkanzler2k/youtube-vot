# Что нового в 2.2.3

### 🐛 Исправлено автообновление (оно не работало вообще)
- **Установка обновления не запускалась.** `DownloadManager` отправляет implicit-броадкаст
  `ACTION_DOWNLOAD_COMPLETE`, а на Android 8+ такие броадкасты не доставляются
  динамически зарегистрированным receiver'ам — только объявленным в манифесте.
  Загрузка доходила до 100 %, файл сохранялся, но установщик не открывался.
  Добавлен манифестный `UpdateDownloadReceiver` (сверяет id загрузки, чтобы не реагировать
  на чужие загрузки в системе).
- **Проверка подписи всегда проваливалась на Android 9+.** Использовался
  `PackageManager.GET_SIGNATURES`; на API 28+ поле `PackageInfo.signatures` всегда `null`,
  и проверка подписи возвращала «файл не прошёл проверку» даже для корректного APK.
  Теперь используется `GET_SIGNING_CERTIFICATES` / `SigningInfo` (сравнение
  apkContents-подписей и истории сертификатов).
