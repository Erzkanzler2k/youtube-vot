# Что нового в 2.1.1

### 🔧 Починено автообновление
- Раньше проверка новой версии происходила только один раз при запуске: если в этот момент не было сети или GitHub не ответил — новость о релизе терялась до перезапуска приложения. Теперь проверка повторяется при каждом возврате в приложение, а при сбое — сама пробуется снова.
- Проверка работает не чаще раза в час, а при ошибках — не чаще раза в 10 минут, чтобы не давить на лимиты GitHub.

### 🔄 Проверить обновления вручную
- В настройках (⚙️) появилась строка «Проверить обновления»: запрашивает новую версию с GitHub прямо сейчас, даже если автообновление выключено. Если новая версия есть — предложит установить, если нет — скажет об этом.
