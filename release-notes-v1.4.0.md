## v1.4.0 — тёмная тема, нижняя навигация и фирменный стиль

**Полностью тёмное приложение:**
- Страница YouTube теперь тоже тёмная, как в оригинальном приложении с тёмной темой
  (Android 10+); на Android 13+ — через нативную algorithmic darkening.

**Нижняя навигация:**
- Вкладки **«Главная / Shorts / Популярное»** с красным индикатором активной —
  как в настоящем приложении. При полноэкранном видео панель прячется автоматически.

**Бренд и стиль:**
- Мини-лого (красный круг + play) и слово «VoT» в фирменном красном `#FF0033`
  в верхней панели.
- Плавное появление и исчезание прогресс-бара загрузки.
- Микро-пульс иконок при нажатии + лёгкая вибрация на всех кнопках и вкладках.

По-прежнему: без рекламы, без входа, закадровый перевод русским голосом и субтитры.
Собрано и опубликовано GitHub Actions автоматически.
