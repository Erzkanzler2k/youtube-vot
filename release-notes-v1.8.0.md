## v1.8.0 — управление внизу, ближе к пальцу

- Кнопки **«назад / вперёд / обновить / выход»** переехали с верхней панели вниз —
  теперь вся навигация в зоне большого пальца, на любом экране.
- Нижняя панель: вкладки **Главная / Shorts / Популярное**, под ними — тонким
  рядом управление. Сверху остался только логотип и название приложения.
- В полноэкранном видео нижняя панель по-прежнему убирается.

По-прежнему: без рекламы, без входа, закадровый перевод русским голосом и субтитры.
Собрано и опубликовано GitHub Actions автоматически.
