# Что нового в 2.1.2

### 🔧 Проверка обновлений через резервные источники
- Раньше приложение спрашивало GitHub напрямую — а из-за блокировок api.github.com может не отвечать, и проверка показывала «не удалось».
- Теперь приложение идёт по цепочке: **GitHub API → страница релиза на github.com → CDN-зеркало jsDelivr**. Если один источник недоступен, пробует следующий. CDN-манифест лежит в самом репозитории и не зависит от блокировки GitHub.
- APK для установки при этом тоже может быть скачан через CDN — подпись всё равно проверяется перед установкой.

### 🔄 Проверить обновления вручную
- Кнопка в настройках теперь проходит по той же цепочке источников и понятно сообщает, когда новая версия есть, а когда её нет.
