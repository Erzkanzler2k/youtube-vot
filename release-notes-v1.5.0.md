## v1.5.0 — фирменный загрузочный экран

- При запуске вместо пустоты — **тёмный сплэш с логотипом, названием и подписью
  «Закадровый перевод»**; иконка мягко пульсирует.
- Как только первая страница загрузилась, сплэш **плавно уходит** (fade ~250 мс),
  и лента проявляется поверх.

Приятный старт на любой версии Android, включая 7–9, где нет нативного сплэша 12+.

По-прежнему: без рекламы, без входа, закадровый перевод русским голосом и субтитры.
Собрано и опубликовано GitHub Actions автоматически.
