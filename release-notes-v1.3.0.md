## v1.3.0 — плавность, «премиальность» и релизы через GitHub

**Плавность и премиальность:**
- **Ripple-отклик** на всех кнопках верхней панели + лёгкая **вибрация** (haptic) при нажатии.
- **Плавное появление страницы** при навигации (fade-in ~220 мс) — никаких резких смен кадра.
- **Адаптивная иконка** (API 26+): тёмный фон + белый «play», корректная маска производителя.
- **Нативный тёмный сплэш Android 12+** — тёмный экран запуска с иконкой, без белого старта.
- **Скроллбары WebView скрыты** — чище, как у нативного приложения.

**Полноэкранное видео:**
- При входе в полный экран приложение **переключается в ландшафт** и прячет верхнюю панель,
  при выходе — **возвращается в портрет**.

**Релизы теперь собирает сам GitHub:**
- Пуш тега `vX.Y.Z` запускает GitHub Actions (Windows runner): build.ps1 (тот же пайплайн),
  подписанный APK, и **автоматическое создание релиза** — эта версия собрана и опубликована
  именно так. Локальная машина не нужна.

По-прежнему: без рекламы (сетевая блокировка + косметика), без входа в аккаунт,
закадровый перевод русским голосом и субтитры через встроенный VoT.
