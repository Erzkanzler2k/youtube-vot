# Что нового в 2.0.0

### 🔄 Автообновление
- Приложение само проверяет, не вышла ли новая версия, и предлагает обновление одним нажатием.
- Загрузка идёт в фоне, файл проверяется по подписи — установить можно только настоящий релиз.
- Нажали «Позже» — напоминание вернётся со следующей версией.

### 🧹 Нижняя панель очищена
- Убраны вкладки «Главная / Shorts / Популярное»: они дублировали навигацию самого YouTube.
- Внизу осталось только удобное управление: назад, вперёд, обновить, выход.

### 🛡️ Установка обновлений
- На Android 8+ система попросит разрешить установку из «неизвестных источников» — приложение само откроет нужные настройки и продолжит загрузку после возврата.
