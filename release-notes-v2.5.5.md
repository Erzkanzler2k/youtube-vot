# Что нового в 2.5.5

Второй этап фонового MediaSession-плеера.

### ✨ Добавлено
- MediaSession получает название видео и название канала из текущей страницы.
- Уведомление показывает название ролика и канал вместо технического текста.
- В MediaSession передаётся длительность и текущая позиция видео.
- Добавлена обработка аудиофокуса: при потере фокуса playback ставится на паузу.
- Уведомление и системные кнопки используют фактическое состояние воспроизведения.
- Метаданные и позиция обновляются во время работы страницы.

### 📋 Проверено
- Сборка Java 8 проходит.
- APK подписан постоянным release-ключом, v2/v3 подпись действительна.
- Обе native-библиотеки обхода входят во все ABI.
- Foreground-service и MediaSession не падают при выключенном экране.

### ⚠️ Ограничение
Playback-контур пока связан с Activity WebView. Если система полностью уничтожит Activity, постоянная очередь и автономное продолжение потребуют следующего этапа — переноса WebView/audio playback в отдельный сервис. В этой версии уже работают системная карточка, позиция и аудиофокус.
